# Note Card | 笔记卡片生成器

**Note Card** is a minimalist, offline-first tool designed for content creators (e.g., Xiaohongshu, Instagram). It converts long text into aesthetically pleasing, paginated image cards with smart layout controls.

**Note Card** 是一个极简风格的离线工具，专为小红书或 Instagram 内容创作者设计。它可以将长文章智能转换为精美的分页卡片图片，并提供灵活的排版控制功能。

---

## ✨ Features / 核心功能

* **智能自动分页 (Smart Auto-Pagination)**
    * Block-based flow logic prevents awkward sentence cutting.
    * 基于段落块的流动布局算法，避免文字在句子中间被截断。

* **推拉式微调 (Push/Pull Adjustment)**
    * Interactive buttons (`⬇️` / `⬆️`) to move paragraphs between pages manually.
    * 独创的“推/拉”交互，允许用户手动将段落移动到上一页或下一页，自由控制每张卡片的篇幅。

* **极简美学 (Minimalist Aesthetics)**
    * Themes: Beige (Default), Pure White, Light Grey.
    * 内置米色（默认）、纯白、高级灰三种极简背景，支持字号与行间距调节。

* **离线与隐私 (Offline & Privacy)**
    * Runs locally. No internet required. No data uploaded.
    * 完全本地运行，无需联网，保护内容隐私。

* **高清导出 (HD Export)**
    * One-click export to gallery via `html2canvas`.
    * 一键生成并保存高清图片到相册。

---

## 🛠️ Tech Stack / 技术栈

* **Core:** React (TypeScript)
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
* **Export:** html2canvas
* **Build Tool:** Vite (Assumed) / Website 2 APK Builder (for Android)
